# Litematic Printer Ling 使用说明与公共服推荐配置

| 项目 | 值 |
| --- | --- |
| 显示名 | Litematic Printer Ling |
| 模组 id | `litematic-printer-ling` |
| 配置文件 | `config/litematic-printer-ling.json` |
| 单版本 jar | `litematic-printer-Ling-<MC版本>.jar`（例：`litematic-printer-Ling-26.3.jar`） |
| 全版本 jar | `litematic-printer-Ling-all.jar` |

---

## 一、上手三步

1. 装好 Litematica + MaLiLib + Fabric API，把 jar 丢进 `mods/`。
2. 游戏内按 `Z,Y` 打开设置，或 Mod Menu → Litematic Printer Ling。
3. 默认停在「核心」页签，前四项就是安全模式相关。

**默认热键**

| 功能 | 默认键 | 说明 |
| --- | --- | --- |
| 工作开关 | `Caps Lock` | 打开后打印机才动作 |
| 切换工作模式 | 未绑定 | 循环 打印 → 挖掘 → 排流体 → 填充 → 铺盖 → 破基岩 → **自定义**（需自行设置按键） |
| 打开设置 | `Z,Y` | |
| 关闭全部模式 | `左Ctrl + G` | 一键停下所有功能 |

---

## 二、工作模式

「核心 → 模式切换」有两个大模式：

- **单模式**：同一时间只跑一种功能，用「切换模式」热键（默认未绑定）循环切换。
- **多模式**：每个功能有独立开关，可同时开启。

单模式里新增了 **「自定义（按功能开关）」**：选到它之后，核心页签会出现 打印 / 挖掘 / 填充 / 排流体 / 铺盖 / 破基岩 的勾选项，勾哪些就跑哪些。
比如你只要打印 + 挖掘 + 填充，就切到自定义、只勾这三项，然后按 `Caps Lock` 全部一起工作。

---

## 三、服务器安全模式（核心页签第一项）

一个开关打包了两套速率预设，绑个热键就能在服务器档和单人档之间切。

### 保守档（开关开启，默认）

套用的是紧跟其后的三项**自定义安全值**：

| 配置项（中文） | 配置键 | 默认 | 说明 |
| --- | --- | --- | --- |
| 安全档 - 放置间隔时间 | `safePlaceInterval` | 2 tick（0.1 秒） | 被服务器吞方块就调到 3~5 |
| 安全档 - 每刻放置方块数 | `safePlacementsPerTick` | 3 | 配合 2 tick 间隔约每秒 30 块 |
| 安全档 - 每刻挖掘方块数 | `safeBreaksPerTick` | 8 | 挖隧道仍慢可调到 10~12 |

开启时 RTT 自适应也一并打开（按你的 ping 把间隔抬到「至少一个往返」）。

### 性能档（开关关闭）

`placeInterval = 0`、每刻放置 8、破坏不限制、关闭 RTT 自适应。

### 两条行为约定

- **只有开关真正翻转时才套用预设**，手动微调过的单项数值不会被每次启动覆盖。
- **开着安全模式时手动改了上面任一项速率参数** → 自动退出安全模式，并且**保留你刚改的值**。

## 四、遍历方向（新增）

「核心 → 遍历方向」决定挖掘 / 填充 / 铺盖 / 排流体 / 破基岩时，候选方块**优先从哪个方向开始处理**：

| 选项 | 适用场景 |
| --- | --- |
| 最近优先（默认） | 原来行为，围绕玩家一圈圈扩，人跟着走最方便 |
| 从下往上 | 挖竖井、从基岩往上清 |
| 从上往下 | 从地表往下剥，先清出落脚面 |
| 从北往南 / 从南往北 | 清大面积平地，一层层推过去 |
| 从西往东 / 从东往西 | 同上，换轴 |

> 说明：选方向后不再按「到玩家的半径」剪枝，改为沿该轴扫过去；可达性过滤仍然生效，够不到的方块不会被点。默认的「最近优先」保持原有逻辑不变。
> 打印（放置方块）的排序仍由「打印 → 打印目标排序」控制，可与遍历方向配合使用。

## 五、其余默认值

| 配置项（中文） | 配置键 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 放置间隔时间 | `placeInterval` | 2 tick | 给出速率窗口的同时保持跟手 |
| 每刻放置方块数 | `placeBlocksPerTick` | 3 | 约 1.5 块/刻 |
| 放置冷却时间 | `placeCooldown` | 6 tick | 同一格失败后的重试间隔，调小更跟手 |
| 每刻挖掘方块数 | `breakBlocksPerTick` | 8 | |
| 挖掘冷却时间 | `breakCooldown` | 6 tick | |
| RTT 自适应间隔 | `placeRttAdaptiveInterval` | 开启 | 按 ping 自动调间隔 |
| 检查玩家交互范围 | `checkPlayerInteractionRange` | 开启 | 只处理够得到的方块 |

> 出现「幽灵方块 / 放置被吞 / 偶尔回退」时，先把 `placeInterval` 调大而不是调小。

## 六、工具切换完全交给 Tweakeroo

本版**移除了内置的自动切换工具**（原来的「自动切换工具」配置项已删除），避免两套选择器互相覆盖：

- 开着 Tweakeroo 的「自动切换工具」→ 由 Tweakeroo 切到最优工具（含耐久保护）。
- 没装 / 没开 → 保持你当前手持的物品，打印机不替你换。
- 破基岩流程仍会自己挑选镐子，这是破基岩机器能成立的前提。

## 七、默认关闭的高风险功能（功能都在，手动开）

| 功能 | 配置项 | 默认 | 说明 |
| --- | --- | --- | --- |
| 挖掘模式 | 自定义/多模式里的 `mine` | 关闭 | |
| 基岩破坏 | `bedrock` | 关闭 | 内置破基岩；自带白名单与多人自适应 |
| 快捷潜影盒 | `quickShulker` | 关闭 | 支持 Quick Shulker / AxShulkers |
| Chest Tracker 远程取物 | `remoteTake` | 关闭 | 仅装了 Chest Tracker 时可见 |
| 虚空仓库补货 / 返还 / 库存 | `voidWarehouseRestock` 等 | 关闭 | 需要服务端装 carpet-Neko-Addition |

功能关闭时不会注册相关协议通道，不会在后台向服务器发握手包。

## 八、界面与反馈

- 缺材料 HUD 默认开启；失败提示每 1.5~2 秒最多一次，且只在真正要显示时才拼文本。
- 页签顺序：核心 → 放置 → 破坏 → 打印 → 挖掘 → 填充 → 铺盖 → 排流体 → 破基岩 → 特殊 → 热键。
- 调试 HUD 默认关闭。

---

## 九、单人 / 自建服想拉满速度

关掉「服务器安全模式」即为性能档；或手动：

1. `placeInterval` → `0`
2. `placeBlocksPerTick` → `8`
3. `breakBlocksPerTick` → `0`
4. `placeCooldown` / `breakCooldown` → `4`
5. `scanTimeBudgetMs` → 大投影卡顿时从 2 降到 1

---

## 十、关于反作弊

- **放置速率**：由 `placeInterval` + `placeBlocksPerTick` 控制。
- **视角特征**：走真实的「看向方块再交互」路径，不是纯数据包静默放置。
- **连续同类方块**：由 `printSortTargets` / `printSortSides` 打散顺序。

仍然被踢时，把 `placeInterval` 提到 `4~6`、`placeBlocksPerTick` 降到 `2` 再观察。
